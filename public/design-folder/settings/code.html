SYSTEM ARCHITECTURE // ABOUT EXPOSURE

Exposure utilizes an end-to-end encrypted protocol to ensure zero-knowledge telemetry transmission. All data payloads are encrypted on-device prior to transmission using an advanced cryptographic implementation.

Cipher Protocol AES-256-GCM
Key Derivation Argon2id
Forward Secrecy Enabled

The AES-GCM (Galois/Counter Mode) model provides both authenticated encryption and data integrity. Your passphrase never leaves the local node, ensuring that without explicit authorization, intercepted packets remain cryptographically opaque.
