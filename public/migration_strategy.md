Database Migration Strategy: JSON Blob to SQLite\n\nThe primary goal is migrating the data from decentralized, file-based JSON blobs into a robust, transactional SQLite database accessible via the HMEM system.\n\nThis involves defining schemas for all previously stored entities (e.g., user signals, group metadata) and creating migration scripts/pipelines that can read the old format, transform it, and write it to the new structured SQLite format. We must ensure data integrity during this process, as loss of history is unacceptable.\n\tKey Components: Data Parser for JSON input -> Transformation Layer (Validation/Normalization) -> SQLite Writer (with transaction control).\n\tRisk Areas: Handling malformed JSON, ensuring proper mapping of complex structures (like nested comments or attachments), and maintaining backward compatibility during phased rollout.
